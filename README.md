# 运行方法说明

## 1.整体说明
本实验多种数据集分类的多种机器学习方法实现。
所有数据集已经包含在./Datasets中。
神经网络训练完成的权重文件保存在./model中。
## 2.安装环境依赖

### 打开命令提示符
`<cmd.exe>`
### 定位到项目文件夹
`<cd .../机器学习B课程设计>`
### 安装依赖库
`<conda install --yes --file requirements.txt>`

## 3.如何运行
### 激活虚拟环境（填写你创建的虚拟环境名）
`<conda activate ur_env_name>`

### 定位到项目文件夹
`<cd .../kcsj>`

### 运行某种方法
`<python RF-AZD.py>`

*替换为对应python文件即可*
